# Support

## English

Use the repository issue tracker for bugs, feature requests, and documentation corrections. Search existing issues first. A useful report includes the extension version, VS Code version, operating system, whether the window uses Remote-SSH, and the command or menu action that failed.

For a remote-listing problem, include a redacted error message and whether the connected host is Linux. Do not include credentials, private keys, tokens, or sensitive absolute paths. Security vulnerabilities follow [SECURITY.md](SECURITY.md), not the public issue tracker.

## 中文

错误、功能建议和文档修正请提交到仓库 Issue；提交前先搜索是否已有相同问题。有效报告应包含插件版本、VS Code 版本、操作系统、是否使用 Remote-SSH，以及失败的命令或右键菜单操作。

若问题与远程目录列举有关，请提供脱敏后的错误信息以及远端是否为 Linux。不要提交凭据、私钥、令牌或敏感绝对路径。安全漏洞请遵循 [SECURITY.md](SECURITY.md)，不要提交公开 Issue。
